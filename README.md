# Acervo de leis municipais de Mimoso de Goiás

Aqui ficam os arquivos em PDF das leis municipais de Mimoso de Goiás (GO), publicados no site da
Câmara Municipal. Os PDFs estão nos **Releases** deste repositório, um por período
(`leis-1989-1999`, `leis-2000-2009`, `leis-2010-2019`, `leis-2020-2029`).

O que tem valor legal é o conteúdo de cada arquivo PDF. O nome de cada arquivo traz o número e o ano
da lei (por exemplo, `Lei-001-1989.pdf`).

O arquivo `manifesto.csv` lista cada PDF com o número de páginas, o tamanho e a impressão digital
(SHA-256), que serve para conferir se um arquivo baixado é o mesmo que foi publicado.
